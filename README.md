# 官方 PK 活动管理后台

基于现有活动管理后台样式还原的交互演示页面，保留 PK 查询、新增、编辑、删除和分组功能。

## 代理消息通知（本次新增）

- 每场 PK 独立开启/关闭通知，新建活动默认关闭，不限制 PK 类型。
- 启用后填写一段通知文案的多语言 Key，以及精确到分钟的北京时间（UTC+8）推送时间。
- 每场 PK 仅允许配置一次提醒，时间须晚于当前时间、不晚于活动结束时间。
- 列表支持通知状态和推送时间展示，并支持按通知状态查询。
- 未发送通知允许修改配置；已发送的通知不允许重复安排。
- 不改变历史活动及已有安排的任务数据。

## 线上访问

https://official-pk-admin-github.vercel.app

GitHub 主分支 `main` 提交后由 Vercel 自动部署。

## 注意：仍为前端交互原型

目前配置数据保存在浏览器 localStorage 中；实际的通知调度、消息推送、语言 Key 文案解析、消息重试、状态回写、发送幂等、历史兼容逻辑均需要接入已有服务端 API 和消息系统。页面显示「待推送」**不代表真实定时推送已注册**。
