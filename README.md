# 官方 PK 活动管理后台

基于原官方 PK 活动后台的交互页面，保留活动查询、新增、编辑、删除和 PK 分组功能。

## 本次代理通知配置

只增加两个配置项：

- **代理通知开关**：默认关闭，各种 PK 类型均可手动开启或关闭。
- **多语言 Key**：开启后显示且必填，仅输入一段通知文案对应的 Key，无需区分标题与正文。

活动列表增加「代理通知」列，只展示 **开启 / 关闭**，鼠标悬停可查看已配置的 Key。

不需要单独配置频次、间隔、推送时间或测试发送；也不再展示通知执行状态、频次和下次时间等列。

## 部署

- GitHub：https://github.com/beaver123-sketch/official-pk-admin
- Vercel：https://official-pk-admin-github.vercel.app

提交 GitHub main 分支后 Vercel 自动发布。

**说明**：页面仍为前端交互原型，数据由浏览器本地保存；真实代理通知发送需业务服务端接入并依据开关及多语言 Key 实现。
